Leonida Legend is an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words with named sources, a five-stage roadmap to the platinum, missable flags, and a checklist that saves progress in the browser with export and import.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. The guide works with the network off — it loads nothing from outside `app/`.
